# Windows Dynamic Island

Dynamic Island для Windows 10 и 11: чёрная капсула вверху экрана, которая плавно меняет форму и
содержимое в зависимости от того, что происходит в системе — музыка, видео, уведомления, громкость,
таймер, загрузки, подключение устройств.

## Возможности

| Функция | Как работает |
|---|---|
| Капсула и анимации | Пружинная физика (spring) для размеров и скруглений, морфинг контента, 60+ FPS, движок анимаций работает только во время анимации (0% CPU в простое) |
| Музыка | Windows GSMTC: название, исполнитель, обложка, play/pause, next/prev, прогресс и перемотка (если источник их даёт), выбор сессии при нескольких источниках |
| Видео | Отдельный видеорежим для YouTube/Twitch/плееров: название, приложение, миниатюра, состояние |
| Визуализатор | Настоящий системный звук: WASAPI loopback → FFT (2048, окно Ханна) → 32 логарифмические полосы. Стили: эквалайзер, волна, минимальные полосы. Захват включается только когда визуализатор на экране |
| Уведомления | Тосты Windows через UserNotificationListener, очередь с приоритетами |
| Системные индикаторы | Громкость, яркость (встроенные дисплеи), батарея, зарядка, USB, Bluetooth, микрофон (mute и «используется») |
| Загрузки | Отслеживание временных файлов браузеров в папке «Загрузки»: размер, скорость, завершение |
| Таймер / секундомер | Запуск, пауза, стоп, +1 мин, уведомление и звук по окончании |
| Дашборд | Клик по пустой капсуле: часы, дата, быстрые таймеры |
| Настройки | Внешний вид, функции, индикаторы, таймер, система, горячие клавиши, диагностика модулей |
| Система | Автозапуск, трей, выбор монитора, скрытие в полноэкранных приложениях, один экземпляр, корректное завершение |

## Требования

* Windows 10 версии 1809 или новее, либо Windows 11 (x64).
* Для сборки: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

## Сборка и запуск

```powershell
cd WindowsDynamicIsland
dotnet build -c Release
dotnet run --project src\WindowsDynamicIsland -c Release
```

Или откройте `WindowsDynamicIsland.sln` в Visual Studio 2022 и нажмите F5.

Скрипты:

```powershell
.\build\build.ps1      # restore + build + тесты
.\build\publish.ps1    # самодостаточный DynamicIsland.exe в artifacts\publish
```

Установщик: после `publish.ps1` откройте `installer\DynamicIsland.iss` в [Inno Setup 6](https://jrsoftware.org/isinfo.php)
и нажмите Compile — получится `DynamicIsland-Setup.exe` (установка без прав администратора).

## Управление

* **Левый клик** по капсуле — развернуть / свернуть. Клик по уведомлению — закрыть его и развернуть текущую активность.
* **Правый клик** — меню: настройки, секундомер, таймер, скрыть, выход.
* Иконка в трее: клик — развернуть, двойной клик — настройки.
* Горячие клавиши по умолчанию (меняются в настройках):

| Действие | Сочетание |
|---|---|
| Развернуть / свернуть | `Ctrl+Alt+I` |
| Показать / скрыть остров | `Ctrl+Alt+H` |
| Play / Pause | `Ctrl+Alt+P` |
| Секундомер (старт / пауза) | `Ctrl+Alt+T` |
| Настройки | `Ctrl+Alt+S` |

Повторный запуск `DynamicIsland.exe` открывает настройки уже запущенного экземпляра.
Параметр `--settings` открывает настройки при старте.

## Честные ограничения платформы

Приложение не имитирует то, чего Windows не предоставляет. Статус каждого модуля виден в
**Настройки → Диагностика**.

* **Медиа (GSMTC).** Браузеры отдают в Windows только одну (последнюю) медиасессию и только если сайт
  использует MediaSession API. Таймлайн (позиция/длительность) у браузеров часто отсутствует — тогда
  полоса прогресса скрыта. Обложку отдают не все приложения.
* **Визуализатор** анализирует общий системный звук (loopback устройства вывода по умолчанию), а не звук
  отдельного приложения.
* **Уведомления.** Требуют разрешения «Доступ к уведомлениям» (Параметры → Конфиденциальность →
  Уведомления). На некоторых сборках Windows API `UserNotificationListener` недоступен неупакованным
  приложениям — модуль сообщит об этом в «Диагностике». Решение — MSIX-упаковка (sparse package)
  с capability `userNotificationListener`.
* **Яркость** доступна только для встроенных дисплеев ноутбуков (WMI `WmiMonitorBrightness`).
  Внешние мониторы не сообщают яркость Windows.
* **Загрузки.** Браузеры не раскрывают общий размер файла во временных файлах, поэтому показываются
  скачанный объём и скорость (неопределённый прогресс) и уведомление о завершении.
* **Микрофон «используется»** определяется по реестру CapabilityAccessManager (Windows 10 1903+).

## Архитектура

```
src/WindowsDynamicIsland/
├── Core/                 EventBus, AppManager (composition root), ModuleManager,
│   │                     IslandController (приоритеты отображения), IslandState, Log
│   └── Models/           общие модели и события всех модулей
├── UI/                   окно-капсула, виды состояний, компоненты, дизайн-система (Themes/)
├── Animation/            Spring-физика, AnimationEngine, Transitions, MorphContentControl
├── Media/                GSMTC: MediaManager, классификация музыка/видео, обложки
├── Audio/                WASAPI loopback, FftProcessor, VisualizerControl
├── SystemIntegration/    уведомления, громкость, яркость, USB/Bluetooth, батарея, микрофон, fullscreen
├── Downloads/            DownloadMonitor
├── Timing/               TimerManager (таймер и секундомер)
└── Settings/             модели, SettingsManager, окно настроек, горячие клавиши, автозапуск
tests/WindowsDynamicIsland.Tests/   xUnit-тесты логики
docs/CONTRACTS.md                   контракты между модулями
```

Поток данных: модули публикуют события в `EventBus` → `IslandController` по приоритетам вычисляет
`IslandState` (что показывать) → UI привязан к состоянию и анимирует переход. Команды пользователя
(play/pause, таймер, развернуть) идут обратно через `EventBus`. Модули независимы: отказ одного
(например, нет доступа к уведомлениям) не влияет на остальные.

Добавить новый модуль: реализовать `IIslandModule`, публиковать события из `Core/Models`,
зарегистрировать в `Core/AppManager.cs`.
